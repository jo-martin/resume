# Jo Martin — Resume

A self-contained HTML resume designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a new public repository, for example `resume`.
2. Add `index.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site is responsive, has no external dependencies, and includes print styling for saving/printing as PDF.

## Updating

Edit `index.html` directly. The technology list is intentionally labelled as career experience so older platforms are not misrepresented as current day-to-day tools.
